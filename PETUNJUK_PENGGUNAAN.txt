Aplikasi Slip Gaji Karyawan ini dibuat lengkap dengan perhitungan otomatis:
- Gaji Pokok
- Tunjangan Makan (Otomatis: Hari Masuk × Tarif/Hari)
- Tunjangan Transport (Otomatis: Hari Masuk × Tarif/Hari)
- Insentif Kerja Tanggal Merah (Otomatis: Jumlah Hari × Rp 75.000)
- Tunjangan Jabatan
- TOTAL PENERIMAAN (PENGHASILAN KOTOR / BRUTO)
- Potongan Pajak PPh 21 (Otomatis sesuai Status PTKP & TER Bulanan PP 58/2023)
- Iuran BPJS (Kesehatan / Ketenagakerjaan)
- Informasi Pinjaman / Kasbon (Total Pokok, Cicilan/Bln, Cicilan Ke/Tenor, & Sisa Pinjaman)
- TOTAL POTONGAN
- GAJI BERSIH (TAKE HOME PAY)
- Terbilang Otomatis (Format teks bahasa Indonesia)

-------------------------------------------------------------------
ATURAN POTONGAN PPh 21 & PTKP:
-------------------------------------------------------------------
1. Menggunakan aturan resmi Tarif Efektif Rata-Rata (TER) Bulanan (PP No. 58/2023 & PMK No. 168/2023).
2. Pilihan Status PTKP Karyawan:
   - TER Kategori A : TK/0 (PTKP Rp 54 Jt), TK/1 (PTKP Rp 58.5 Jt), K/0 (PTKP Rp 58.5 Jt)
   - TER Kategori B : TK/2 (PTKP Rp 63 Jt), TK/3 (PTKP Rp 67.5 Jt), K/1 (PTKP Rp 63 Jt), K/2 (PTKP Rp 67.5 Jt)
   - TER Kategori C : K/3 (PTKP Rp 72 Jt)
3. Sistem secara otomatis mencocokkan Penghasilan Bruto ke layer persentase tarif TER (0%, 0.25%, 0.5%, 0.75%, dst) dan menghitung nominal pemotongan pajak PPh 21.
4. Tersedia 3 mode: Otomatis TER, Manual Input, dan Bebas Pajak (Non-Pajak).

-------------------------------------------------------------------
PILIHAN UKURAN KERTAS & ORIENTASI CETAK (PORTRAIT):
-------------------------------------------------------------------
Orientasi Cetak default dikunci pada **PORTRAIT (Tegak)** sesuai standar dokumen slip gaji resmi.
Tersedia 5 pilihan ukuran kertas yang dapat dipilih langsung sebelum mencetak:
1. 📄 [A4 Full Page]   : Standar 1 halaman penuh A4 Portrait (dokumen resmi).
2. 📑 [A4 Bagi Dua]    : 1 lembar A4 Portrait berisi 2 slip kembar (Lembar Karyawan & Arsip Kantor) dengan garis potong gunting di tengah.
3. 📋 [Kertas A5]      : Ukuran setengah A4 Portrait/Landscape.
4. 📑 [F4 / Folio]     : Ukuran HVS Folio Portrait standar kantor Indonesia.
5. 🧾 [Struk 80mm]     : Ukuran gulungan printer kasir thermal struk.

Pilihan Orientasi:
- 📱 [Portrait (Tegak)] : Pengaturan default untuk semua ukuran kertas.
- 💻 [Landscape (Mendatar)] : Pilihan opsional jika ingin format mendatar.

-------------------------------------------------------------------
FITUR DATABASE TERPISAH (INSERT & RIWAYAT):
-------------------------------------------------------------------
- 💾 [Simpan ke Database] : Tombol terpisah untuk insert data slip ke penyimpanan lokal.
- 🗄️ [Database & Riwayat] : Modal manajemen riwayat, filter pencarian, load data, hapus, dan Export Rekap ke Excel/CSV.

-------------------------------------------------------------------
CARA MENGGUNAKAN:
-------------------------------------------------------------------
1. Klik ganda file [ Buka_Slip_Gaji.bat ] atau buka langsung [ index.html ] di browser.
2. Pilih ukuran kertas dan orientasi (default: Portrait).
3. Isi data karyawan & nominal di form sebelah kiri (Tunjangan Makan & Transport otomatis dihitung per hari masuk kerja).
4. Klik tombol "💾 Simpan ke Database" untuk mengarsipkan.
5. Klik tombol "Cetak Slip" untuk mencetak langsung dalam mode Portrait atau simpan sebagai PDF.

6. Template Excel:
   Buka file [ Template_Slip_Gaji_Excel.xls ] langsung dengan Microsoft Excel jika ingin mengedit via spreadsheet.
